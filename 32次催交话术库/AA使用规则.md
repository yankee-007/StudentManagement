# 催交话术库 · 使用规则（AA使用规则）

> 对应《方案思考》**方案2**：统一轮次模板 + 每次催交前重新诊断。
> 素材来源：《催作业催上课话术库》9 大风格 × 7 大场景，按「频次策略（第1次温柔 → 逐轮加码 → 深水区霸道/公告）」编排为 32 轮。

## 一、目录结构

```
催交话术库/
├── AA使用规则.md          ← 本文件（先读我）
├── 第1次催交话术.md
├── 第2次催交话术.md
└── ... 第32次催交话术.md
```

## 二、使用流程

1. 记录该生已催次数 → 打开对应「第N次催交话术.md」
2. **重新诊断**该生当前进度（每次必做，进度会变，不得沿用旧诊断）
3. 按诊断结果选场景分支（全未启动 / 缺课单节点 / 缺作业单节点 / 散落多节点）
4. 替换变量（{学生姓名} {第X节课} {第X节课的作业} {散落节次}）
5. 多节点欠账（含散落型）句尾追加「可别越拖越多哦」；单节点不加
6. 通读检查 ≤ 200 字后发送

## 三、学生状态诊断规则

- 状态值：T = 已完成，F = 未完成，N = 无数据（**N 一律忽略**，不纳入进度判断）
- 检查顺序：按课时从前往后，先看该节课课程，再看该节课作业
- 四类判定：

| 类型 | 判定条件 | 话术核心 |
|---|---|---|
| 全未启动型 | 第1节课课程（C1）未完成 | 催第1节课开启 |
| 缺课型 · 单节点 | 仅 1 节课课程未看，其余前序已完成 | 催补对应课 |
| 缺作业型 · 单节点 | 仅 1 节课作业未完成（该课已看） | 催完成对应作业 |
| 散落多节点型 | ≥2 个未完成节点（连续或散落，如第3、4、8、12节课） | 列出全部待补节次，重点最靠前 1 个，补「别越拖越多」 |

- 同一节课「课程未看 + 作业未完成」视为该节课欠账，在散落节次里写一次即可（如 第3、4、8、12节课）

## 四、变量替换

| 变量 | 替换内容 | 示例 |
|---|---|---|
| {学生姓名} | 学生真实姓名 | 王籽栋 |
| {第X节课} | 具体课程节次 | 第2节课 |
| {第X节课的作业} | 具体作业节次 | 第2节课的作业 |
| {散落节次} | 待补节次列表（按节次升序、顿号分隔） | 第3、4、8、12节课 |

- {散落节次} 可按该生欠账明细加后缀细化：如「第3、4、8、12节课的课程」「第3、4、8、12节课的作业」「第3、4、8、12节课的课程和作业」
- 待补节次较多（≥8 节）时可缩写：如「第3、4、8、12节课等 8 节课」
- **禁止编造未完成项**：只催诊断结果中真实存在的节点

## 六、防重复与边界

1. **防重复红线**：同一条句式对同一学生连续使用不超过 2 次；轮次间已天然切换风格大类，无需额外干预
2. **内向敏感型降级**：第 19 / 20 / 31 / 32 轮（霸道/终极通牒）禁用，替换为同轮次温柔暖心或心灵鸡汤句式，强度封顶 ★★★
3. **节点投放**：疯狂星期四 → 第 11 轮；直播课前夜 → 第 8 / 16 轮；期末收尾 → 第 27 轮 + 第 20 / 32 轮
4. **不编造**：只催真实存在的未完成节点；N 值一律忽略
5. **语气底线**：默认温和友好为主，霸道类仅用于深度逾期且师生熟络场景

## 七、长度与格式

- 替换后话术 ≤ 200 字，适合即时通讯发送
- 必须明确提及具体节次（如「第3、4、8、12节课」或「第2节课的作业」），禁止泛泛「记得完成作业」
