## 数据口径

- 只统计**在读**真实学员，不含退课／冻结／补位。
- 累计完课率／作业率 = 第 1～N 节全部完成的人数 ÷ 在读人数。
- 差值 = 累计完课率 − 累计作业率；考核线：**优秀 ≤5pp / 良好 ≤10pp / 及格 ≤15pp / 不合格 >15pp**。
- **只写已开课的节次**：本班当前为第 1、2、3、4 节；未开课节次不写入、不参与统计
  （课程总节数 32 节，仅用于说明考核线适用范围）。
- 全部取自最近一次催办的真实冻结快照；历史批次只读，不受后续获取影响。

## 独立学习概览预览（2026-10-07）

本轮用户选择先评审独立模块预览，正式 QML 尚未修改。打开本地 `learning-overview-local.html`：

- 「最新数据」为默认页，只读取导出时最新批次聚合快照，显示人数/累计率/差值、逐节表和完课次数；无对比或目标选择器。切换其他页签的历史批次不会改变最新页，数据时间与导出时间均显式标注。
- 「批次对比」选择查看批次与对比批次；顶部默认双方最新共同节次。指标、图例、悬浮提示及逐节表明确列出两批数据和变化；滑块调整图表范围。
- 「目标追踪」独立选择评估批次和节次，试算目标；走势可观察完课率、作业率或差值，显示目标线及同节次最近几批变化。不受双批次选择影响。
- 三页签支持键盘切换；侧栏「催办工作台」仅展示职责分工。

```powershell
python preview/build_overview.py
# 可用 --db 指定班库、--class-name 指定展示名称；默认沿用原 py169 预览来源。
node preview/check_overview.cjs
```

自检需可解析 Playwright（可通过 NODE_PATH 指向运行时包目录）和现有 Chrome。检查脚本沿用本机 py169 第11/12批作为分母变化样例；换数据库时应调整样例批次。截图输出到忽略目录 output/overview。

构建仅通过 SQLite mode=ro 查询批次与聚合看板，不实例化 Database，不导出学员姓名或反馈正文，不执行刷新。新增完课次数表从version>=3分布快照读取；可跟进人数按各批次人工是标记聚合计数计算，SQL只读取学习快照字段和campaign_followup_status，不导出姓名、学号或反馈正文。生成 HTML 含真实聚合数据，已被忽略，不提交；模板、构建和检查脚本可入库。

逐节比较必须是相同节次；历史未开到该节时留空。走势统一使用选择的目标评估节次，避免各批末节变化造成混淆。不同分母显式提示，禁止将比例变化直接称为催办新增人数。最新批次仅代表导出时状态，正式刷新仍可改写它。

两条率默认85%是目标试算示例，尚未成为正式考核要求；差值目标沿用15/10/5pp。目标不保存。差值人数试算假设完课人数不变，通过补齐累计作业降低差值；完课、作业各自目标独立计算。

完课次数表保留原八列，并附两批分桶人数/比例对比。人数为恰好完成k节，完课人数/完课率为完成不少于k节的累计人数/比例，与第1～N节全部完成的累计口径不同。历史分布缺失不反推；缺失分布显示—，可跟进标记表尚未建立时显示—，完成人数与退课留空。开课节数不同可能改变最高桶覆盖范围，对比需结合开课进度。

导出验证：`python -m unittest discover -s preview -p test_overview_export.py -v`，只用内存数据库，无正式库写入。

当前口径：每行N的「可跟进人数」＝完成0～N节且在本批可跟进状态为是的在读非补位学员数，包含当前档。各行重叠不可相加；标记独立于反馈状态，不自动分析文字，无标记默认否。只有旧库尚无标记表时显示—。正式应用保持恰好k节分桶，独立预览按用户要求累计0～N节。

指定反馈样本评审：`python preview/build_overview.py --preview-batch 16`。使用第16次自身学习快照与本批人工标记，默认单批看板及查看/目标选择均指向第16次，页面明确标记历史样本与真正最新批次。各历史批次独立统计人工标记；无参数仍默认最新批次。找不到指定批次时直接报错，不静默回退到别的批次。

第16次按用户授权人工审阅本次反馈填入是/否；预览仅导出聚合数量，正式库备份和逐人标记不入Git。
