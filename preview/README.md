## 数据口径

- 只统计**在读**真实学员，不含退课／冻结／补位。
- 累计完课率／作业率 = 第 1～N 节全部完成的人数 ÷ 在读人数。
- 差值 = 累计完课率 − 累计作业率；考核线：**优秀 ≤5pp / 良好 ≤10pp / 及格 ≤15pp / 不合格 >15pp**。
- **只写已开课的节次**：本班当前为第 1、2、3、4 节；未开课节次不写入、不参与统计
  （课程总节数 32 节，仅用于说明考核线适用范围）。
- 全部取自最近一次催办的真实冻结快照；历史批次只读，不受后续获取影响。

### 两种统计口径

累计学习率＝第1～N节全部完成的人数÷该批全班在读人数（含免催、不含补位），取已保存 version>=2 的累计快照。旧单节快照不能作为累计率，缺失也不能从完成次数反推。逐节对比必须同节次，缺失时显示 —；不同分母会提示，变化不解释为催办因果效果。

完课次数来自该批冻结学员的 `completed_courses`；旧格式仅在该字段不存在时读取 `completed_total` 的已完成计数。无有效计数不归入0次，未获取人数明确提示；人数和比例分母均按该批本次催办范围（eligible、微信、真实姓名及在读非补位）。每行人数＝恰好完成k节；完课人数/完课率＝完成不少于k节的累计人数/比例，与第1～N节全部完成不同。两批最高桶不同会留空，不虚构未保存的桶。

可跟进人数＝该批本次催办中恰好完成k节且人工「可跟进状态＝是」的人数，各行独立，不累加低次数。不解析反馈正文，也不使用旧反馈状态推断。覆盖提示展示已填写、是、否、未填写数量；整批未标记显示 —，已标记全否显示0，部分标记仅统计确认是并提示未填写人数。双批变化同时受人员范围和标记覆盖影响。完成人数、退课暂无数据源，保留空单元格。

第9次与第16次沿用用户授权后保存的本批人工标记。正式工作台看板仍为原全班分桶；本次催办范围是当前独立概览预览的口径，正式接入待评审。

目标试算默认两条率85%仅为示例，尚未成为正式要求；差值目标为15/10/5pp。目标不保存；差值人数试算假设完课人数不变、通过补齐累计作业降低差值。

自检需可解析 Playwright（可通过 NODE_PATH 指向运行时包目录）和现有 Chrome。当前检查脚本以本机 py169 全部批次、第9/16次人工标记和第11/12次分母变化为验收样例；换库需调整样例。内存库测试仅使用虚构学员。浏览器自检覆盖选择器隔离、数据与图表一致、缺失降级、分桶/标记计数、目标输入、键盘、导航、缩放及1280×820/1000×700布局，截图在 `output/overview`。
