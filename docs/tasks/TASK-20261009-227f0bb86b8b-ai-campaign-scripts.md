## 需求与验收

在「催办工作台 → 生成群发名单 → 群发中心」增加 AI 自然话术，不使用反馈历史、承诺记忆或状态机。

用户本轮明确确认：
- **按当前课程节次自动选模板，可手选**，不按学员已催次数。当前节次取本批快照 dashboard.opened；第 N 节用第 N 份，超过32取第32份；没有已开课节次时需手选。
- **失败项自动重试后留空，名单照常创建**，显示失败说明，允许补写或重试失败项。

实现标准：32份只读素材；当前学员数据与模板生成每人一条话术；逐人／分批／一次可选；学号作为 JSON key 且集合一致；默认重试2次、指数退避；覆盖已知欠课／欠作业、≤200字、多节点句尾提醒；API Key 只存 keyring；配置服务商、地址、模型、温度、输出 tokens、超时、重试、默认方式、批大小、并发批数；结果直接写既有 recipients.content，名单与发送仍分开。
