## Findings（关键依据与值得保留的失败尝试）

- **失败尝试 1（已放弃）**：用 `completed_courses >= N` 反推同群累计率。实测与看板 `completed` 不等价（第12次：重算 85 人 vs 存储 90 人），误差量级与要观察的催办效果相当，会给出"看着专业但站不住"的数字。
- **失败尝试 2（已放弃）**：把差值线挂主图右轴。视觉上盖住两条率线、把考核线压到下部，已改为独立差值面板。
- **模型缺陷（已修正）**：三层柱状图若同 `stack` 会把"已完成"也叠进去导致超过 100%；现只让"已开课但未达标 + 一节未完成"叠成其余数，三段合计恒为 171（自检断言）。
- **数据不一致发现（既有问题，未修）**：第11次看板 `total=172` 与其学员快照在读 171 人不一致（第12次相反）。原因是 `created_at` 会被刷新改写而 `campaign_dashboards` 只在最新批次刷新，两者并非同一时点。**不是本任务引入，本轮未修改**，但它会让历史批次之间的全班比率比较带噪声。
- **分母口径**：看板分母为"批次内在读非补位学员"，含请假免催者（与 ADR-010 一致）；本任务沿用，未改口径。
