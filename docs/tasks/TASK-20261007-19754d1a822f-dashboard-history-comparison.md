## Findings（关键依据与值得保留的失败尝试）

- **失败尝试 1（已放弃）**：用 `completed_courses >= N` 反推同群累计率。实测与看板 `completed` 不等价（第12次：重算 85 人 vs 存储 90 人），误差量级与要观察的催办效果相当，会给出"看着专业但站不住"的数字。
