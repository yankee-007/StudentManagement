# ADR-014：正式目标与跨批次承诺独立于催办快照

## Status

Accepted。2026-10-08用户确认独立今日工作台、完整跟进闭环、固定第1～N节、沿用最新批次人员、少量补齐优先、具体项目承诺及手动刷新，随后要求实施。真实班级人工验收待进行。

## Context

概览的临时试算不持久化，批次反馈和人工可跟进标记不能表达跨批次承诺及期限。请求期间更改承诺、保留的旧数据和同学员多编辑器可能误判或覆盖人工输入。

## Decision

- 每班新增一个正式目标与独立承诺/事件表；不修改ADR-013的只读概览与临时试算。N变化归档旧周期，已有承诺继续。
- 三项共同达标，最新有效批次范围与概览一致，周期人员变化单独说明。确定项目才计算贡献，先按项目数量、再按差值与目标贡献排序。
- 每学员最多一条未结束承诺；选择项目完成后结束，累计统计仍要求范围内全部完成。反馈、人工标记、联系、发送、学习结果独立。
- 仅调整后启动且成功导入的实际返回人员可核验；保存逐项证据。未知和未返回不猜测，采集途中调整的承诺等待下一次采集。
- 编辑器token和修订保护多窗口草稿；失败阻止离开。今日列表遵循ADR-007，名单创建复核在读/微信/免催，现有画像/催办名单规则保持原样。
- 读不迁移；首次写前备份已有班库，新增存储，不重写历史快照。应用内提示及手动采集，不增加后台服务。

## Consequences

增加独立Qt模块与三个每班表；名单通过现有JSON元数据关联，无群发库迁移。人机验收需要真实班级试用，自动测试使用虚构人员及临时库。
