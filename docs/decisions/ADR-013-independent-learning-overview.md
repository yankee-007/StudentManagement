# ADR-013：独立学习概览、只读批次范围与历史降级

## Status
Accepted。用户在TASK-20261007-19754d1a822f交接确认四页签与口径，并明确正式实施。正式视觉体验仍待验收；本决定部分替代ADR-010的呈现/历史分布限制，不改既有快照写入格式。

## Context
工作台承担逐人联系和反馈，切换其批次会影响正在处理的学员。早期批次缺看板或只有单节数据，已有累计快照也可能与冻结成员在读人数不一致。免催、无微信、已完成者仍需进入全班统计；人工是/否独立于反馈。

## Options Considered
- 复用工作台筛选/批次：会串联操作游标并缩小统计范围，不采用。
- 用完成次数反推累计率、重写旧看板：无法还原第1～N节完成交集，不采用。
- 正式代码依赖HTML预览或安装额外图表包：采用现有QtQuick Canvas/RangeSlider，预览仅作为评审和只读对账工具。

## Decision
- 侧栏增加独立LearningOverview，最新固定实际最新批次；历史单批、双批对比、目标追踪各自保存批次/节次选择，切班重置，目标不持久化。工作台只保留概览入口，切模块继续先保存反馈。
- 概览只读当前班SQLite事务，所有批次入口保留；统计范围为本批冻结成员的在读非补位，不套eligible/微信/免催或表格筛选。不构造Database或CampaignStore作取数探针。
- 累计仅接受version>=2、分母与成员范围一致、分子/比率有效的快照。旧单节、缺快照、范围不一致或双方无共同节次明示空值，不改原记录。双方曲线、图例、实线/虚线、5/10/15pp线与同节次明细一起展示，变化不解释为催办因果效果，分母不同明确提示。
- 完课次数读取completed_courses，字段不存在才兼容completed_total；显式未知不回填或放入0次。按实际恰好k节分桶，≥k的累计人数作完课人数，未知仍在全班分母内。此读取兼容可以展示早期成员分布，不从旧聚合率反推，不修改旧dashboard.py将超N并入N的写入规则。
- 可跟进为恰好该次数且本批人工是者，各桶独立；整批未填写为—，全否为0，部分标记只数确认是者；列出已填写/是/否/未填写。完成人数、退课两列保留空单元格，无启动清理或反馈自动分类。
- 默认85%只作试算示例，率输入0～100%，差值目标15/10/5pp；人数按全班分母向上取整，差值试算假设完课人数不变、通过补齐作业降差值。走势按同一累计节次读取截至评估批次最近至多5批，缺点留空。

## Rationale
独立状态保护联系工作流；冻结成员和原累计证据保持一致，缺失时降级比套用新分母可靠。原生图表延用现有Qt运行环境，可在临时库真实QML中验证交互和布局。

## Consequences
新增只读聚合服务及专用通知，不增加数据库表或外部副作用。旧LearningDashboard和Workflow.dashboard保留兼容，正式界面改从概览服务读取；原界面冒烟迁到新入口。真实平台端到端及用户主观体验不由自动测试替代。
