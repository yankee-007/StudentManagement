# ADR-012：未接听电话不等于学员已回复

## Status
Accepted。2026-10-07用户明确指出填写「未接听电话」被自动归为已回复不正确。

## Context
原自动保存按所有非空内容写入reply。默认快捷项包含未接听电话，导致工作台回复状态、可跟进统计和已有历史记录判定失真。

## Options Considered
- 仅修改新保存的kind：旧记录和只读预览仍会误计。
- 批量迁移正式反馈：会写入历史资料，本轮不采用。
- 统一显式否定项判定，并在读取旧记录时兼容（采用）。

## Decision
app.feedback_status统一判定：kind不是reply时不计已回复；按分号/换行拆分后，仅含明确「未接听电话」「未回复」项不计回复。其它非空项沿用既有规则；明确否定与其它回复项并存时有回复。该规则不做自由文字的意愿推断，不解析企微聊天。

新submit/save_feedback写正确kind；旧记录读取时同样判定，不改写其原文或kind。编辑框保留全部反馈文字，可追加后来回复或清空。历史批次仍禁止反馈编辑。保存后实时重算看板，正式工作台可跟进只计已回复，待反馈不计入。独立预览复用同一函数识别旧误标，原文不导出。

## Rationale
联系尝试不是学员回复。用显式快捷反馈修正已知错误，同时保留原非空反馈兼容行为和历史原始资料。

## Consequences
已保存的未接听记录无需重新填写即可显示未回复；重新编辑后才按新kind持久化。独立预览累计0～N节的可跟进范围仍属预览需求，未借本修复搬入正式看板。
