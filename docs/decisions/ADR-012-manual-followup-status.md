# ADR-012：可跟进状态独立于反馈状态

## Status
Accepted。2026-10-07用户要求独立是/否字段，并确认好的、OK、知道了等已回应可填是。

## Context
反馈非空仅表示有记录，未接听电话也可能有记录。文字不统一，不能持续自动推断补课意愿。此前反馈状态判定修复已按用户要求回退。

## Options Considered
- 按反馈kind统计：误把联系尝试算作可跟进。
- 保存时解析文字：与用户要求人工填写不符。
- 独立批次人工标记（采用）。

## Decision
campaign_followup_status以批次/学员为主键，仅是/否，未填写显示否。手工标记不会被反馈保存、学习刷新或新建批次覆写；新批次不继承旧值。真实学员可通过详情选择修改，按班级/批次/学员捕获身份校验。历史可补充此独立标记，历史学习/反馈仍只读。

正式看板按恰好完成k节分桶计在读非补位且标记是者；独立概览预览后续按用户澄清改为本次催办范围内恰好N节的人数与其中是标记者，不累加低次数；全班累计学习指标保持原分母。均不再用反馈状态判定。导出、字段管理和筛选包含新字段。

## Rationale
联系记录与是否继续跟进是不同的人工判断，独立保存才能允许修正而不改原反馈。

## Consequences
第16次按用户授权人工审阅144条反馈后填入：回应或答应补课为是，未接听、未回复、退课意向、无反馈为否；未把该规则作为长期自动分类器。其他批次未填写默认否。写入前用SQLite备份，核对原表不变；真实数据/备份不入Git。
